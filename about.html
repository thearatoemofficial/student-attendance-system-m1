About Us

The Student Attendance System is a frontend web project created for learning HTML, CSS, JavaScript, Git, and GitHub collaboration.

Project Purpose

This project helps students understand how to build a modern website and collaborate using GitHub Pull Requests.

Main Features

  • ✅ Record student attendance
  • ✅ Upload student photos
  • ✅ Display students as cards in a grid
  • ✅ Save records in browser localStorage
  • ✅ Delete one record or clear all records
  • ✅ Use GitHub branches and Pull Requests

Development Team

This system is developed by a team using GitHub collaboration, branches, commits, Pull Requests, reviews, and merge.
